# ЗЕРНО — сайт сети кофеен

Многостраничный сайт кофейни на Bootstrap 5.3.3. Откройте `index.html` в браузере или запустите локальный сервер командой `python -m http.server 8000`. Bootstrap и шрифты подключаются через CDN.

Меню, акции, мероприятия, информация о кофейне и контакты находятся на отдельных страницах. В меню доступны фильтры, а выбранные позиции сохраняются в корзине браузера. Форма заявки не подключена к серверу.
